# 产品官网：首页介绍视频

2026-11-03：`k-box-wiki` 的 `/wiki` 首页保留左侧产品定位介绍与入口，右侧原知识流向示意图替换为《问学知识平台 · 基础介绍》视频。问学是上位品牌，K-BOX / 问学知识平台是旗下产品，视频使用已纠正该命名关系的 N01 v3。

## 页面与播放

入口为 `k-box-wiki/src/app/page.tsx`，播放器交互在 `src/app/components/ProductIntroVideo.tsx`，样式在 `src/app/globals.css`。采用服务端渲染的原生 `<video controls playsInline preload="none">`，首屏显示封面与可聚焦的播放按钮，点击后切换为原生控件，用户主动播放，提供浏览器原生进度、音量与全屏控制；视频区域保持 16:9，手机端随首页布局排列在文案下方。播放器关联产品标题与描述，保留不支持视频的浏览器下载链接。

视频已内嵌中文字幕，另提供 WebVTT 可选字幕轨，不默认开启以避免重复字幕。页面资源均使用包含 `/wiki` basePath 的同源绝对路径；加载失败时允许重试或下载 MP4。不增加第三方播放器、外部视频服务或登录要求。

## 素材与部署

制作维护源是本仓库 [episodes/N01](../episodes/N01/README.md)。当前发布副本保存在 `k-box-wiki/public/media/`：

- `k-box-intro-v3.mp4`：1920×1080、25fps、H.264/AAC，232.04 秒。
- `k-box-intro-v3.jpg`：对应视频封面。
- `k-box-intro-v3.vtt`：由同版 SRT 转换的中文字幕。
- `intro-video.json`：来源版本、提交号、时长及资源 SHA-256。

Next.js 通过 `/wiki/media/` 提供静态资源，原有 Dockerfile 的 `COPY public` 已覆盖这些文件。镜像构建与运行不读取相邻视频仓库，没有新增 API 或环境变量。视频更新使用新的版本文件名，同步替换首页路径、时长、封面、字幕及清单，再构建部署。文档中心导航归类和 Markdown 检索索引不变。
