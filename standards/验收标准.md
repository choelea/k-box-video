# 验收标准

## 内容与学习结果

- 单条有一个清晰结果，成片 2–7 分钟。
- 任务实操有目标、前提、操作与结果核验闭环。
- 功能与录制环境一致，记录产品版本；未知时如实标注，不能推断。
- 回答及引用来自真实运行，假设输入明确标注。未执行的动作不能说已执行。

## 配音与字幕

- 全部品牌词逐处核听，“问学”不拆读；数字、术语、缩写正确。
- 字幕保持正式写法，断句符合语义，时间与配音对应。
- 配音响度统一，拼接自然，没有截音或长段空白。

## 画面与技术

- 关键按钮、回答和引用可读，讲到哪项依据，画面能看到对应内容。
- 等待节选、慢放等编辑方式明确标注，不伪造响应耗时。
- MP4 为 H.264/AAC，当前基线 1920×1080、25fps；全片可解码，字幕与章节存在。
- 浏览器可播放及跳转；需人工检查关键镜头和音画同步。

## 可维护性

- 原始录屏、截图、配音和讲解源文件齐全；不依赖聊天目录或临时会话文件。
- assets.json 路径和哈希有效；所有需要保留的媒体匹配 Git LFS 规则。
- 构建文件与原素材分离，凭证和浏览器状态不入库。
- 自动检查通过只代表技术项通过，不能自动清除品牌核听或内容审阅待办。
