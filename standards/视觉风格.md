# 视频视觉风格 · v0.1

状态：2026-11-02 用户确认“视觉也可以”，作为后续视频统一视觉标准。模板与参数位于 shared/brand/v0.1/visual/，N02 v2 已应用本标准，优化前版本另存归档；N01 v2 也已应用本标准并重录官网六页。

## 色彩与品牌

延续官网营销页与 N02 企业版的深色、金色方案；产品界面保持原有浅色与功能状态色。现有产品图标来自 k-box-app-ui/public/logo.png，保留原色，不改绘。此图标为产品仓库现有资产，不声称已完成独立品牌设计或商标审定。

| 用途 | 色值 |

## 画布与文字

- 1920×1080、25fps，H.264/AAC。
- 左右安全边距 80px；品牌栏在顶部，底部为独立字幕区。
- 当前字体为系统苹方；不打包分发系统字体。其他系统更换可用中文字体后须重查排版。
- 片头品牌字号约 88–92px，内容标题 60–64px，正文 30–32px，辅助信息 23–26px，字幕 36px。
- 字幕通常一行，按语义分句，优先不超过 26 个汉字；品牌词不拆分。内容较长时重新分句并按语音时点对齐，不单纯缩小字体。

## 四种公共画面

1. 片头：产品完整名称“问学知识平台”，系列或主题信息；3–6 秒内进入正文。每集可以直接用本集问题作为主标题，不强制每集重复播放完整品牌动画。
2. 章节与图解：一个清晰标题，2–3 个要点或必要流程；装饰不能压过内容。
3. 实操：保持真实产品界面，区域基线 x=80、y=116、1760×880；按可读性决定是否裁切放大，字幕不覆盖关键按钮或原文。
4. 片尾：3–4 秒收束，可提示一个关联主题；不承诺尚未排期视频的发布日期。

样片的 N02 画面来自已保存真实引用截图；片头、章节、片尾为概念图解。不同画面的性质不能混淆。

## 节奏与声音

转场优先 0.18–0.3 秒淡入淡出；正常操作保持原速，节选、加速或慢放另行标注。默认不加背景音乐。配音响度目标 -16 LUFS，真峰值不超过 -1.5 dBTP；品牌读音通过后才能转为标准音参考。

## 修改与复用

参数见 visual/tokens.json，HTML 模板见 visual/template.html。基础样式只维护 visual/base.css，公共模板与各集 HTML 统一引用；CSS 与 JSON 参数仍须同步，尚未实现自动从参数生成样式。

新主题用当前模板创建，记录模板版本。更改公共模板先生成样片再核验，不自动批量重导旧视频。已有片子的品牌读音问题仍单独追踪。
